# Gabe Benavides Portfolio

Personal portfolio built with Next.js, React, TypeScript, and Tailwind CSS.

## Getting Started

Install dependencies and run the development server:

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

## Project Structure

- `app/` contains routes and global styles.
- `components/` contains shared page and layout components.
- `lib/site.ts` contains shared navigation and contact links.
- `public/` contains static assets, including the resume.

## Scripts

- `npm run dev` starts the local development server.
- `npm run lint` runs ESLint.
- `npm run build` creates a production build.
- `npm start` serves the production build.
